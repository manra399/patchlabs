Questions

Do you need my database password?

No. We work from your code alone. The fix arrives as a pull request, and it reaches your live app through your normal deploy once you merge it.

What if a fix breaks something?

Every fix is tested on a rebuilt copy of your database first. If a page would behave differently, the pull request says so, and any change that page needs is included.

Who decides who should see what?

You do. When a fix depends on a business choice, for example whether sellers’ emails should be public, we ask you in plain English with a recommended answer.

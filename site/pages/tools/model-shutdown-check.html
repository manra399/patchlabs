Will your app’s AI stop answering on 14 January?

OpenAI switches off GPT-4o, GPT-4o mini, GPT-4.1 and GPT-4.1 mini in its API on 14 January 2027, and o3, GPT-5 and GPT-5 mini on 11 December 2026. An app that still asks for one of them gets an error instead of a reply. Paste your code, .env or config: your browser lists every model and API feature on OpenAI’s shutdown list, with the date, the days left and the replacement OpenAI names. The dates

Five shutdown days before the end of January.

Taken from OpenAI’s deprecations page. OpenAI emails the account owner, which in an app built for you is often not the person who reads the code. Fine-tuned models stop on the same day as the model they were trained from.

Azure OpenAI runs its own retirement schedule, so check Microsoft’s model retirement page if your app calls Azure.

How it reads your code

It looks for the model name, wherever it’s written.

Model names are plain strings, so they turn up in code, .env files, JSON settings and YAML. The check matches whole names only, longest first, so gpt-4o-mini-tts isn’t reported as gpt-4o, and short names like o3 count only in quotes or after model=.

Where do I find the model name?

Search your project for model, gpt- and OPENAI. In Lovable and Bolt apps the call is often in a Supabase Edge Function (supabase/functions/*/index.ts); check the .env and your host’s environment settings too, because the name is often only there.

What happens on the day?

OpenAI says a shut-down model “no longer accepts requests through the standard API”, so the request returns an error. Many AI-built apps catch that error and show nothing, which looks like the feature broke for no reason.

Can I just swap the name?

Usually, but test first. Newer models can take different parameters, format answers differently and cost a different amount. OpenAI’s advice is to run representative requests on both models and compare before switching. The guide has a two-step way to do that.

How current is the list?

It is generated from OpenAI’s deprecations page; the date it was read is shown with each result. OpenAI adds new shutdowns every few months, so check again when you change models.
